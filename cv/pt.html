Projetos em Produção

Yasmin — Agente de IA para pedidos via WhatsApp (projeto próprio)  ·  ~100 pedidos a cada 2 dias

Agente de IA (OpenAI + orquestração em n8n) que interpreta a conversa no WhatsApp, decide quando consultar cardápio, monta itens/combos/extras e cria o pedido via API REST de terceiros, com memória de curto prazo em Redis e notificação de status pelo mesmo canal.

  • Incidente recorrente resolvido na raiz: a API do fornecedor expunha, sem documentar, um campo interno com o mesmo formato numérico dos IDs reais — o que fazia o modelo emitir IDs inválidos. Corrigido com guardas de validação em código, após um ajuste de prompt já ter falhado.
  • Falha silenciosa em produção havia meses: uma ramificação de fluxo nunca conectada, sem erro visível ao usuário.
  • Engenharia reversa de uma regra de precificação de combos não documentada pela API de terceiros.
  • Bateria própria de testes de falha real (credencial inválida, timeout de rede) em cópias isoladas do fluxo, sem risco ao atendimento em produção.
